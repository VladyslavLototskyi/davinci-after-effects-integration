# DaVinci Resolve ➔ Adobe After Effects Exporter

[English](README.md) | **Русский**

**Версия 1.0.0** • Быстрый экспорт помеченных клипов и субтитров из DaVinci Resolve в After Effects в один клик.

---

## ⚡ Быстрый старт (Установка за 1 минуту)

### Windows
1. Скачайте архив или папку релиза.
2. Дважды кликните по файлу **`install.bat`**.  
   *(Скрипт сам найдёт папку DaVinci Resolve и установит плагин).*

### macOS / Linux
Запустите в терминале:
```bash
python3 install.py
```

### Ручная установка (без установщика)
Просто скопируйте файл **`ae_export.py`** в папку скриптов DaVinci Resolve:
- **Windows**: `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\`
- **macOS**: `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/`
- **Linux**: `~/.local/share/DaVinciResolve/Fusion/Scripts/Utility/`

---

## 🚀 Как пользоваться

1. Откройте любой проект и таймлайн в **DaVinci Resolve**.
2. Выделите нужный клип (или несколько клипов), нажмите правой кнопкой мыши $\rightarrow$ **Clip Color** $\rightarrow$ выберите **Orange** *(Оранжевый)*.
3. В верхнем меню DaVinci нажмите:  
   **Workspace** $\rightarrow$ **Scripts** $\rightarrow$ **Utility** $\rightarrow$ **`ae_export`**
4. **Готово!** Автоматически откроется **Adobe After Effects** с готовой композицией.

---

## ⌨️ Настройка горячей клавиши (в DaVinci)

Чтобы экспортировать выделенный фрагмент за полсекунды:
1. В DaVinci откройте: **DaVinci Resolve** $\rightarrow$ **Keyboard Customization** (или `Ctrl + Alt + K`).
2. В строке поиска введите `ae_export`.
3. Назначьте удобное сочетание клавиш (например, `Ctrl + Alt + E`).
4. Нажмите **Save**. Теперь экспорт запускается нажатием одной комбинации!

## ✨ Что переносится в After Effects

- **Точный тайминг и длительность**: композиция в After Effects создаётся ровно по длительности экспортируемого клипа (без пустого пространства в конце).
- **Исходное медиа**: файл автоматически импортируется в проект AE в отдельную папку `Resolve Imported Media`.
- **In / Out точки**: с точностью до кадра выставляются точки входа и выхода из исходника.
- **Retime (изменение скорости)**: скорость клипа автоматически пересчитывается в `Stretch` слоя AE.
- **Трансформации**:
  - Позиция (`Position`)
  - Масштаб (`Scale`, включая независимые оси X/Y и Flip)
  - Поворот (`Rotation`)
  - Непрозрачность (`Opacity`)
  - Кадрирование (`Crop Left / Right / Top / Bottom` в виде векторной маски)
- **Субтитры**: дорожка субтитров автоматически переносится как текстовые слои After Effects с сохранением точных таймингов и стилизации (шрифт, размер, цвет, чёрная обводка). Переносятся только реплики выбранного фрагмента.
- **Отчёты**: в папке `Видео/Resolve_to_AE` создаются структурированные файлы `report.md` и `report.json` со всеми деталями и предупреждениями (например, если у клипа другой FPS).

## ⚙️ Настройки и CLI (для продвинутых)

Скрипт можно запускать из командной строки:
```bash
python ae_export.py --color Orange --font "Montserrat" --font-size 52
```

### Параметры:
- `--color`, `-c` — цвет клипов для экспорта (по умолчанию `Orange`, можно указать `All` для всей дорожки).
- `--output-dir`, `-o` — папка сохранения файлов (по умолчанию `~/Videos/Resolve_to_AE`).
- `--proxy` — брать прокси-файлы вместо оригиналов (если созданы в DaVinci).
- `--no-subtitles` — не экспортировать субтитры.
- `--no-open` — сгенерировать скрипт `export.jsx`, но не запускать After Effects автоматически.
- `--font` — шрифт для текстовых слоёв субтитров (по умолчанию `Arial`).
- `--font-size` — размер шрифта (по умолчанию `48`).
- `--full-timeline` — создать композицию на длину всего таймлайна Resolve.

## 📋 Системные требования

- **DaVinci Resolve**: Studio или Free (версии 18, 19, 20, 21+)
- **Adobe After Effects**: версии 2020 – 2026+ (любой установленный AfterFX.exe)
- **ОС**: Windows 10/11 (64-bit) или macOS
- **Python**: используется встроенный Python из DaVinci Resolve, сторонних библиотек устанавливать не требуется.
